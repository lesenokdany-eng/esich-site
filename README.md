# ЕСИЧ — готовый комплект сайта

В комплекте:
- `public/index.html` — сайт ЕСИЧ;
- `server.js` — сервер и API;
- `package.json` — запуск через Node.js;
- `data/profiles.json` — постоянное хранение зарегистрированных участников;
- `.env.example` — пример настройки пароля администратора.

## Запуск

Требуется Node.js 18 или новее.

1. Откройте терминал в папке проекта.
2. Задайте пароль администратора.
3. Запустите `npm start`.
4. Откройте `http://localhost:3000`.

### Linux/macOS
```bash
ADMIN_PASSWORD="ваш_пароль" npm start
```

### Windows PowerShell
```powershell
$env:ADMIN_PASSWORD="ваш_пароль"
npm start
```

Пароль администратора не хранится в HTML и не отправляется пользователям до входа.

## Важно для размещения в интернете

Для постоянной работы сайт нужно разместить на сервере/хостинге, где поддерживается Node.js. Файл `data/profiles.json` должен находиться на постоянном диске, иначе регистрации могут исчезнуть после перезапуска/переразвертывания.

Для реального публичного запуска рекомендуется использовать HTTPS и резервное копирование `data/profiles.json`.

## Размещение в интернете через Render

Этот проект уже подготовлен для Render. В Render создавайте именно **Web Service**, а не Static Site, потому что ЕСИЧ использует Node.js-сервер и API.

1. Создайте аккаунт на GitHub.
2. Создайте новый репозиторий, например `esich-site`.
3. Распакуйте этот архив.
4. Загрузите ВСЕ файлы и папки проекта в репозиторий GitHub. В корне должны находиться `package.json`, `server.js`, `render.yaml` и папка `public`.
5. Откройте Render и выберите **New → Web Service**.
6. Подключите GitHub и выберите репозиторий `esich-site`.
7. В настройках проверьте:
   - Language/Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
8. В Environment Variables добавьте:
   - Key: `ADMIN_PASSWORD`
   - Value: придумайте новый пароль администратора.
9. Нажмите **Create Web Service**.
10. После успешного Deploy Render выдаст публичный адрес вида `https://имя.onrender.com`. Его можно отправлять другим людям.

Render официально поддерживает Node.js Web Services и публичный `onrender.com` адрес. Бесплатные Web Services могут автоматически засыпать после периода бездействия, поэтому первый вход после простоя может занять некоторое время.

ВАЖНО: текущая версия хранит регистрации в `data/profiles.json`. На хостинге без постоянного диска такие изменения могут потеряться при переразвертывании. Для постоянного хранения регистраций лучше подключить PostgreSQL или другое постоянное хранилище перед реальным публичным запуском.

Не публикуйте пароль администратора в GitHub и не вставляйте его в `index.html`.
